# Security Policy

## Supported Versions

Security updates and patches are provided for the current active release of the Open Agentic Engineering Framework (OAEF):

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The OAEF community takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

If you believe you have found a security vulnerability in OAEF:

1. **Do not create a public GitHub issue.**
2. Send an email describing the vulnerability to the project maintainers or open a **Private Vulnerability Advisory** via GitHub Security Advisories.
3. Include the following details:
   - Type of vulnerability (e.g. secret leakage, arbitrary code execution, path traversal in scripts).
   - Step-by-step instructions or proof of concept to reproduce the issue.
   - Potential impact on systems running OAEF or projects generated by OAEF.
   - Any proposed remediation or mitigation.

### Response Timeline
- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Resolution & Disclosure:** Coordinated release with patch and security advisory.

## Secret Scanning & Memory Protection

OAEF includes built-in automated secret scanning in its governance engines (`oaef lint` and `oaef audit`). The system scans for:
- API tokens (OpenAI, GitHub, AWS, Anthropic, Google Cloud)
- Private cryptographic keys (`-----BEGIN PRIVATE KEY-----`)
- Personally Identifiable Information (PII)

Committing secrets or tokens to living memory (`docs/wiki/memory/handoff.md`) or documentation is strictly forbidden by the OAEF Working Contract.
