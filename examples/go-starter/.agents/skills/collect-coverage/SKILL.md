# Collect Coverage (Go)

> **Stack Profile:** Go
> **Governance Standard:** OAEF v1.1.0 (Author: Felipe Carvalho)
> **Skill Class:** primary

## Mission
Extract native Go coverage, compare it with the repository's baseline floors, and enforce the Monotonic Ratchet: floors rise, never fall.

## Territory
- `coverage.out` — the Go coverage profile produced by `go test -coverprofile`.
- `coverage.html` — the human-readable rendering, generated on demand.
- `docs/wiki/metrics/baseline.json` — the declared floors.
- `docs/wiki/metrics/history.json` — the recorded trajectory.

## Coverage Extraction
- Run the suite with coverage and race detection:
  `go test ./... -race -covermode=atomic -coverprofile=coverage.out`.
- Derive the module total:
  `go tool cover -func=coverage.out | tail -n 1`.
- Render a browsable report when reviewing hotspots:
  `go tool cover -html=coverage.out -o coverage.html`.
- Scope excludes generated code, `*_test.go`, `tool/` and `cmd/` shims unless the repository declares otherwise.
- Record the extracted number in `docs/wiki/metrics/history.json` with the commit reference.

## Monotonic Ratchet
- Read the floors from `docs/wiki/metrics/baseline.json`; compare the extracted total against them.
- When the total meets or exceeds the floor, the gate passes; when it falls below, the gate fails and the shortfall is reported.
- When the total rises, raise the floor in the same change — the ratchet never loosens.
- Never lower a floor to make a build green; a legitimate drop requires an explicit, documented decision.
- The gate is `oaef quality-gate` / `oaef audit` (native: `go run tool/governance.go quality-gate`).

## Repository Conformance Gate
- Run `oaef doctor` (native: `go run tool/governance.go doctor`).
- Run `oaef lint` (native: `go run tool/governance.go lint`).
- Run `oaef clean-code` (native: `go run tool/governance.go clean-code`).
- Record unresolved findings in `docs/wiki/memory/handoff.md`.

## Exit Criteria
- `coverage.out` is generated by a race-enabled run.
- The extracted total is recorded and compared against the baseline floors.
- Any floor increase is committed alongside the change that produced it.

## Anti-Patterns
- Lowering a baseline floor to pass the gate.
- Excluding a package from the profile to hide low coverage.
- Committing `coverage.out` or `coverage.html` as a build artifact.
- Reporting a coverage number from a run without `-count=1`.
