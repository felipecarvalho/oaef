# Screen Builder (TypeScript & React/Next.js)

> **Stack Profile:** TypeScript & React/Next.js  
> **Governance Standard:** OAEF v1.0.0 (Author: Felipe Carvalho)  
> **Quality Gate Policy:** Strict mathematical audit and Clean Sizing.

## Mission & Scope
Construct or refactor vertical feature modules and screens in TypeScript & React/Next.js adhering to Clean Sizing and layered architecture.

## Guidelines
- Maximum 300 LOC per file.
- Delegate state to `React hooks / Zustand`.
- Extract helper sub-components into separate dedicated files.
- Ensure all user-facing strings are localized or externalized.
