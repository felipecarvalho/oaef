# Screen Builder (React Native)

> **Stack Profile:** React Native  
> **Governance Standard:** OAEF v1.0.0 (Author: Felipe Carvalho)  
> **Quality Gate Policy:** Strict mathematical audit and Clean Sizing.

## Mission & Scope
Construct vertical feature screens using React Navigation and Clean Sizing discipline.

## Guidelines & Invariants
- Ensure screen container files do not exceed 200 LOC.
- Delegate complex navigation and state logic to custom hooks or state containers (Zustand/Redux Toolkit).
- Extract complex list headers, footers, and cards into separate files.
