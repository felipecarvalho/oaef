# Ui Preview (React Native)

> **Stack Profile:** React Native  
> **Governance Standard:** OAEF v1.0.0 (Author: Felipe Carvalho)  
> **Quality Gate Policy:** Strict mathematical audit and Clean Sizing.

## Mission & Scope
Develop and inspect isolated React Native components using Storybook or sandbox preview screens.

## Guidelines & Invariants
- Create Storybook stories or isolated preview wrappers for every shared UI component.
- Test varied prop permutations, loading states, and error states without running full app navigation flows.
