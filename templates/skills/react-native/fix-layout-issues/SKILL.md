# Fix Layout Issues (React Native)

> **Stack Profile:** React Native  
> **Governance Standard:** OAEF v1.0.0 (Author: Felipe Carvalho)  
> **Quality Gate Policy:** Strict mathematical audit and Clean Sizing.

## Mission & Scope
Resolve Flexbox layout errors, Yoga engine overflows, keyboard avoidance, and safe area defects.

## Guidelines & Invariants
- Diagnose and correct unbounded flex shrink/grow issues.
- Use KeyboardAvoidingView and react-native-safe-area-context for responsive viewport adaptation.
- Ensure layouts adapt properly across differing screen densities and aspect ratios.
